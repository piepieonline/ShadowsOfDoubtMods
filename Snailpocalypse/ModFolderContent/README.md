# Pie's Snailpocalypse

Snailpocalypse, as seen in Reggie's video: https://www.youtube.com/watch?v=Ouq6IP4IJnw

# Manual Installation

* Ensure you have BepInEx BE and dependencies installed
* Extract the mod to `.\BepInEx\plugins\`, so you should have `.\BepInEx\plugins\Snailpocalypse\Snailpocalypse.dll`
